# Your docs home page

The search home is the front door of your docs: a heading, a large search box, quick search buttons and topic cards. Readers who press Enter see full results right there, below the box.

## Add it

The setup wizard can create a "Documentation" page with the search home on it. To add it yourself, put one of these on any page:

- the **Docs Search Home** block,
- the **Waypost Search Home** Divi module,
- or the shortcode `[waypost_search_home]`.

Then choose that page as the **Docs home page** in **Waypost, Settings, Navigation**. With the Waypost docs layout, the search home is added to the docs home page automatically if it is not there yet.

## Fill it in

Go to **Waypost, Settings, Search home**.

- **Heading** and **Intro line:** for example "Search the Magpie docs" and "Everything you need to install, configure and run Magpie."
- **Quick searches:** up to six buttons. Each has a **label** readers see and the **search** it runs. A label can be a question, such as "How do I share an album?", running the search "shared albums".
- **Topic cards heading** and **Topic cards:** up to six cards. Each has an icon, a title, a short line of text and the page it opens.

Good quick searches and topic cards come from Search insights: use your most popular searches. See [Search insights and page feedback](08-insights-and-feedback.md).

## Where full results show

In **Waypost, Settings, Search, Full results show**:

- **On the docs home page, inside the search home** (recommended). Results appear below the search box without leaving the page, and the sidebar menu stays in place. Search boxes elsewhere on the site send readers here too.
- **On a separate results page.** A page of its own with the `[waypost_search_results]` shortcode. The wizard can create it.

Either way the address includes the search words, so readers can share a link to their results and the Back button works.
