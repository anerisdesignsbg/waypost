## 3. What Aneris Docsway is

Aneris Docsway is a **WordPress plugin** that turns the pages a site already has into a proper documentation site, with **smart search that answers questions**. There is no content migration: pages stay where they are, page addresses do not change, and pages built with Divi, the block editor or any page builder keep their layouts.

**Who it is for:** businesses and agencies with a WordPress site that need product docs, a help centre, a knowledge base, user guides or internal manuals, without moving content into a separate docs system.

**How it works in one line:** put your pages into sections, and Docsway builds the menu, search, contents, breadcrumbs and page navigation around them. A five-minute setup wizard does the work.

**The main selling point:** search that understands readers. It answers a question like "How do I share an album?" by showing the exact section of the exact page that answers it, with a short summary on top, instead of a plain list of pages.

## 4. Features

### Free version (WordPress.org)

**A complete docs site in one click**
- Docs layout: sidebar menu, "On this page" contents, breadcrumbs, previous and next links, inside the site's own header and footer or with a clean docs bar of its own.
- Sidebar menu built from sections, with sections inside sections, drag-and-drop ordering and a mobile menu.
- Search home page: a large search box, up to six quick search buttons and topic cards with icons.
- Seven ready-made styles: Follow my theme, Modern, Minimalist, Classic, Light, Dark, and Auto light and dark with a switch for readers. Any accent colour.
- Page extras: last updated date, reading time, copy links on headings, copy buttons on code, "Was this page helpful?" buttons.

**Smart search that answers questions**
- Best answer: the section that answers the search is shown on top with a short summary and a link straight to it, followed by other pages that cover the same thing.
- Understands questions: words like "how do I" are ignored.
- Finds other forms of a word: "installing" finds "install".
- Fixes typing mistakes: "dokcer" finds "docker", and says so.
- Instant results as readers type, from anywhere with Ctrl+K or Cmd+K.
- Highlights on arrival: the page a reader opens highlights their search words and the matching section.
- Searches only the docs, never blog posts or shop pages.
- Runs entirely on the site: no outside service, nothing to set up.

**Learn what readers need**
- Search insights: popular searches and, more usefully, searches that found nothing.
- Page feedback: answers to "Was this page helpful?", least helpful pages first.

**Works with your site**
- Classic themes, block themes and Divi.
- Blocks, Divi modules and shortcodes.
- Pages, posts or any custom post type; its own sections or an existing taxonomy.
- Setup wizard and built-in tutorials.

### Aneris Docsway Pro (paid add-on)

Everything in the free version, plus:
- **Search inside documents:** PDF, Word, PowerPoint, Excel, OpenDocument and text files from the Media Library join the doc sections. Search finds words inside them, and the menu lists them with a file type label.
- **Synonyms:** teach search your readers' own words, for example "pic" for "photo".
- **Topic filters:** readers narrow search results to one section, with a count for each.
- Automatic updates and email support for the licence period.

**Planned for Pro (say "coming", never promise dates):** multiple docs sets, private docs for chosen user roles, fuller search insights with exports, native Divi 5 modules.
