Adds document search, synonyms and topic filters to Waypost.

== Description ==

Waypost Pro is an add-on for the free Waypost plugin. It keeps everything Waypost does and adds:

* **Search inside documents:** PDF, Word, PowerPoint, Excel, OpenDocument and text files from the Media Library join your doc sections. Docs search finds words inside them, and the menu lists them with a file type label.
* **Synonyms:** teach search your readers' own words, for example "pic" for "photo".
* **Topic filters:** readers narrow search results to one section, with a count for each.

== Installation ==

1. Install and activate the free Waypost plugin from Plugins, Add New.
2. Upload `waypost-pro.zip` under Plugins, Add New, Upload Plugin, then activate it.
3. Enter your licence key when asked. Updates then arrive like any other plugin update.
