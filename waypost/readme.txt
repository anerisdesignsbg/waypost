Turn the pages you already have into a documentation site. No migration, no URL changes.

== Description ==

Most documentation plugins ask you to move your content into their own post type. Waypost works the other way round: you put your existing pages into sections, and Waypost builds the docs experience around them.

* **Sidebar menu** built from your sections, with drag-and-drop ordering, the current page highlighted and a mobile toggle.
* **Docs-only search** with instant results, highlighted matches, keyboard navigation and links that jump straight to the matching heading.
* **Ctrl+K / Cmd+K search** from anywhere on a doc page.
* **Search home** for your docs start page: a large search box, up to six quick search buttons and topic cards with icons.
* **Ready-made styles**: Follow my theme, Modern, Minimalist, Classic, Light and Dark.
* **On this page** contents with the current heading highlighted as you scroll.
* **Previous and next** links that follow your menu order.
* **Breadcrumbs** with schema.org markup.
* **Copy buttons** on code blocks.
* **Search insights**: see what readers search for and what they could not find.
* **Setup wizard** and built-in tutorials.
* Works with the block editor, Divi and any theme through shortcodes.
* Can use a taxonomy you already have, for example one created with CPT UI.

== Installation ==

1. Upload the `waypost` folder to `/wp-content/plugins/` or install the zip from Plugins, Add New.
2. Activate the plugin. The setup wizard opens automatically.
3. Follow the five steps, then place the Docs Menu in your doc page sidebar.

== Frequently Asked Questions ==

= Will my page addresses change? =
No. Waypost never moves or copies content.

= Does it work with Divi? =
Yes. Waypost adds Divi modules for the menu, search, contents, previous / next and breadcrumbs. Use them in a Theme Builder template. On Divi 5, add a Code module with the Waypost shortcodes, such as [waypost_menu], because the modules are not in the Divi 5 module list yet.

= Is any personal data stored? =
Search insights store only the words searched, a count and the number of results. No IP addresses or user details.
